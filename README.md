# Nashville Song Editor

**A modern, browser-based song editor for musicians using the Nashville Number System.**

Nashville Song Editor makes it easy to create, organize, and manage song arrangements using Nashville chord notation.

Designed with keyboard players and live musicians in mind, the application combines chord editing, song structure management, lyrics, and MIDI export in a clean, responsive interface.

### Key Features

- **Nashville Number System** — Edit chords using numbers, including minor, seventh, suspended, and slash chords.
- **Song Structure** — Add, remove, duplicate, and rearrange sections such as Intro, Verse, Chorus, Bridge, and Outro.
- **Chord Charts** — Four measures per row with precise beat-based chord placement.
- **Lyrics** — Add lyrics to individual song sections and position words relative to measures and beats.
- **MIDI Export** — Export playable chord notes, tempo, time signature, key signature, and song-section markers.
- **Song Library** — Save, search, and manage multiple songs locally.
- **Print Support** — Generate clean A4 chord charts.
- **Stage Mode** — A simplified, musician-friendly performance view.
- **Light & Dark Mode** — Automatic system theme detection with manual overrides.
- **JSON Import & Export** — Back up and transfer your songs.

### Technology

Built with **HTML, CSS, and vanilla JavaScript**. No installation, external frameworks, or backend server required.

Simply open the HTML file in a modern web browser to start creating arrangements.

### Purpose

The goal is to provide musicians with a fast, intuitive tool for preparing songs, organizing chord progressions, and working with arrangements during rehearsals and live performances.
